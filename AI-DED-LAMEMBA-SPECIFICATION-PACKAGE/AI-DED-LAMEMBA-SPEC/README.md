## Prinsip

Dokumen bukan sekadar daftar nama file/page. Setiap specification harus menjelaskan:

- tujuan;
- pengguna;
- elemen UI;
- data yang dibutuhkan;
- action;
- state;
- validation;
- permission;
- workflow;
- API;
- database impact;
- security impact;
- testing.

Jika sebuah feature belum memiliki informasi yang cukup, tuliskan `TBD` dan jangan mengarang requirement.
